Project: Book Notes

Description: Dynamic book tracking app where users submit a book name, rating (1-10), description, and ISBN.

Features:
-  PostgreSQL database for persistent storage of book entries
-   Open Library API integration to fetch covers by ISBN with fallback for missing covers
-   Admin authentication - protected route with password gate that unlocks add / edit / delete controls for book cards
Developer note:
Original prompt from Angela Yu's Complete Full-Stack Web Development Bootcamp (Udemy). Extended beyond the prompt with admin authentication, full CRUD (edit/delete), rating system, and Open Library cover handling with fallbacks.
